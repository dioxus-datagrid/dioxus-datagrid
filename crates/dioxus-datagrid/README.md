# dioxus-datagrid

Headless, accessible data grid hooks and unstyled primitives for Dioxus 0.7.

Built on [`datagrid-core`](https://crates.io/crates/datagrid-core). Platform neutral — no `web-sys`,
so the same code runs on web, desktop and mobile. The styled component is distributed separately
through the component registry via `dx components add data_grid`.

Status: in development — see [PLAN.md](https://github.com/dioxus-datagrid/dioxus-datagrid/blob/main/PLAN.md).
