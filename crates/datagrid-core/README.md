# datagrid-core

Framework-agnostic data grid logic: sorting, filtering, paging, selection, virtualization math
and keyboard navigation. Pure Rust, no UI framework dependency.

The Dioxus bindings live in [`dioxus-datagrid`](https://crates.io/crates/dioxus-datagrid).

Status: in development — see [PLAN.md](https://github.com/dioxus-datagrid/dioxus-datagrid/blob/main/PLAN.md).
